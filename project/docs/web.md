# Web-версия «ЗапишИИ»

Веб-клиент — вторая оболочка того же ассистента, что и Telegram-бот. Он не
дублирует бизнес-логику: все сценарии идут через `/api/v1`, поэтому задачи,
встречи, напоминания и поиск видны в обоих каналах.

Прототип: <https://lustily-endowed-newfoundland.cloudpub.ru>. Для проверки
достаточно зарегистрироваться по email: у нового аккаунта будет пустой
таймлайн. Демо-пользователь `demo` с seed и CSV-корпусом доступен через API
(`X-Demo-User: demo`) при `ALLOW_DEMO_AUTH=true`.

## Стек

| Слой | Технология | Зачем |
|---|---|---|
| UI | React 18 + TypeScript + Vite | быстрый SPA-прототип без лишних зависимостей |
| Стили | чистый CSS, чёрно-белая дизайн-система | полный контроль над типографикой и SVG-сценой |
| Состояние | React hooks + localStorage для токена | минимальный порог входа |
| API | FastAPI `/api/v1` | общий контракт с ботом |
| Auth | email + password, PBKDF2-SHA256, HMAC access token | простая, но настоящая авторизация |
| Данные | PostgreSQL + SQLAlchemy async | те же таблицы `users`, `events`, `pending_actions` |
| E2E | Playwright | проверка сценариев в реальном браузере |

Осознанно не добавлялись Tailwind, UI-kit, React Router и state manager:
для прототипа хватает трёх экранов и нативных средств. Если проект пойдёт
дальше, следующим шагом будут React Router, refresh-токены и компонентный
UI-kit.

## Экраны

- **Вход / регистрация** — отдельный экран с минималистичной SVG-сценой.
  Показывается, если в localStorage нет валидного токена.
- **Ассистент** — чат с текстом и голосом, быстрые примеры, уточняющие
  вопросы, история диалога после перезагрузки и кнопка «Очистить чат».
- **Голосовой режим** — отдельный экран «звонка»: браузер слушает микрофон,
  отправляет распознанный текст в чат и озвучивает ответ. Пауза около
  2 секунд завершает реплику; диалог продолжается без ручных нажатий.
- **Таймлайн** — вкладки «Активные» / «Выполненные»; календарь месяца с
  отметками дней, где есть записи, и фильтром по выбранному дню; периоды
  сегодня / 7 дней / 30 дней / все; создание, редактирование, выполнение и
  удаление событий, повтор `daily`/`weekly`/`monthly`. Выполненные уходят из
  общего списка в отдельную вкладку и сортируются по времени завершения.
- **Поиск** — поиск по названию и описанию с сниппетами и score.
- **Профиль** — имя, email, дата регистрации, таймзона и привязка Telegram по
  одноразовому коду из `/link`.
- **Напоминания** — in-app баннер для просроченных напоминаний с кнопкой
  «Понятно»; работает без Web Push.

## Голос

- **Распознавание** — `SpeechRecognition` (Web Speech API) с `lang="ru-RU"`.
  Промежуточные результаты показываются сразу, финальные накапливаются, поэтому
  перезапуск распознавания браузером не теряет фразу.
- **Озвучка** — `speechSynthesis`: выбирается русский голос, ответ читается
  после каждого хода. Отдельная кнопка динамика озвучивает любое сообщение в
  чате.
- **Без ключей и без загрузки аудио на сервер.** Всё происходит в браузере;
  `STT_PROVIDER`/`TTS_PROVIDER` на backend для веба не нужны.
- Если Web Speech API недоступен, экран голосового режима объясняет это и
  предлагает текстовый чат. Микрофон требует HTTPS или `localhost`.

## Авторизация

1. `POST /api/v1/auth/register` — email, пароль, имя; пароль хешируется
   PBKDF2-SHA256 с солью.
2. `POST /api/v1/auth/login` — проверка пароля, выдача access-токена.
3. `GET /api/v1/auth/me` — профиль по `Authorization: Bearer <token>`.
4. Клиент хранит токен в `localStorage` и добавляет его ко всем запросам.
5. При `401` токен очищается, приложение возвращается на экран входа.

`X-Demo-User` остаётся только для старых тестов и локальных клиентов и
отключается через `ALLOW_DEMO_AUTH=false`. Telegram-бот по-прежнему
использует `X-Telegram-Id` + `X-Bot-Secret`.

## Дизайн

- Только чёрный, белый и тёплый бумажный серый.
- Крупная антиква для заголовков, моноширинный шрифт для служебных подписей.
- Жёсткие рамки, смещённые тени, сетка из точек — ощущение печатного
  прототипа, а не очередного SaaS-дашборда.
- На входе — сдержанная SVG-сцена без ASCII-робота; при
  `prefers-reduced-motion` анимация отключается.
- Мобильная версия: чат остаётся в пределах экрана, навигация
  прокручивается горизонтально, боковые карточки уходят вниз.

## Запуск

```bash
cd project/backend
alembic upgrade head
uvicorn app.main:app --reload

cd project/frontend
npm ci
npm run dev
```

Открой `http://localhost:5173`, зарегистрируй аккаунт и создай первое
событие. Vite проксирует `/api` на `http://127.0.0.1:8000`.

## Ограничения прототипа

- Access-токен живёт в localStorage; refresh-токенов и отзыва сессий пока нет.
- Голос работает через браузерный Web Speech API: серверного STT/TTS в вебе
  нет. Качество зависит от браузера и наличия русского голоса в системе.
- Веб-напоминания — in-app баннер с polling, без Web Push.
- Нет восстановления пароля и подтверждения email.
