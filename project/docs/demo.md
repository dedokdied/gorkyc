# Демо

## Подготовка

```bash
cd project
python scripts/seed_demo.py --user demo
# опционально: corpus для богатого поиска
python scripts/import_csv.py --user demo
```

Backend: `uvicorn app.main:app --reload`. Web: `npm run dev` в
`project/frontend`. Открыть `http://localhost:5173`.

Без внешних ключей работает `LLM_PROVIDER=rule-based`; голос в браузере
требует `STT_API_KEY` или локальный `faster-whisper`. Текстовый ввод доступен
всегда.

## Telegram MVP

1. Открыть бота, `/start`.
2. «Напомни завтра в 10 позвонить Ивану».
3. «Поставь встречу с Иваном завтра» → «В 15:00».
4. «Что у меня завтра?».
5. «Найди задачи про договор».
6. Отправить голосовое сообщение с той же фразой.
7. Показать, что после перезапуска данные сохранились.
8. Дождаться напоминания или показать `reminders` в БД.

## Web

1. Открыть сайт, зарегистрироваться по email и паролю (или войти).
2. В чате: «Напомни завтра в 10 позвонить Ивану» — появится карточка в
   «Таймлайне».
3. Создать встречу через чат, уточнить время кнопкой или текстом.
4. В «Таймлайне» отметить событие выполненным и удалить другое.
5. В «Поиске» найти созданную запись; после импорта CSV можно искать
   «договор Иваном» и проверить устойчивость к падежам.
6. Нажать «Голос», разрешить микрофон и отправить короткую фразу.
7. Проверить мобильную ширину: навигация, чат и карточки остаются читаемыми.

## Автоматическая проверка

```bash
cd project
python scripts/e2e/smoke.py

cd frontend
npm run e2e
```

`smoke.py` проверяет API по Telegram-auth; Playwright — браузерные сценарии на
демо-пользователе.
