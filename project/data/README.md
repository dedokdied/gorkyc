# Data

Данные для seed и проверки поиска.

## Файл

`voice_assistant_events_1000_77e927b5d2 (1).csv` лежит в корне репозитория.

- Колонки: `id, date, time, text`.
- Кодировка: UTF-8 с BOM.
- 1000 строк, 376 уникальных текстов (624 дубля).
- Даты: 2024–2027, время 08:00–20:00.
- Текст содержит падежные ошибки («Отправить договор Иваном») — это нормально,
  поиск должен быть устойчив.

## Как использовать

1. Импорт в БД для демо.
2. Корпус для golden-set поиска: 50–100 запросов + ожидаемые записи.
3. Проверка дедупликации и классификации типов.

Скрипт импорта: `../scripts/import_csv.py` (создать).
