# Data

Данные для seed и проверки поиска. Это синтетический корпус, не «боевые»
данные пользователя.

## Файл

`voice_assistant_events_1000_77e927b5d2 (1).csv` лежит в корне репозитория.
Скрипт импорта также ищет CSV в этой папке; путь можно передать через `--csv`.

- Колонки: `id, date, time, text`.
- Кодировка: UTF-8 с BOM.
- 1000 строк; 376 уникальных текстов, но полный ключ `(text, date, time)`
  уникален для всех строк.
- Даты: 2024–2027, время 08:00–20:45.
- Текст содержит падежные ошибки («Отправить договор Иваном») — это нормально,
  поиск должен быть устойчив.

## Как использовать

```bash
cd project
python scripts/import_csv.py --dry-run
python scripts/import_csv.py --user demo
```

1. Импорт в БД для демо и наполнения таймлайна.

3. Проверка дедупликации и классификации типов.

Скрипт импорта: `../scripts/import_csv.py`.
