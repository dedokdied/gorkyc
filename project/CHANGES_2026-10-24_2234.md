## Что не проверено / осталось

1. **Telegram вживую**
   - Бот-контейнер запускался, но не смог получать апдейты.
   - `api.telegram.org` резолвится в fake-IP `198.18.8.34`, TLS-рукопожатие обрывается.
   - WARP подключался нестабильно; MantaRay VPN включён, но Telegram и Instagram по TLS не проходят.
   - Нужен VPN/прокси, который реально пускает Telegram, затем проверить `/start`, онбординг, текст, уточнения и группы.

2. **Полный backend-набор с PostgreSQL**
   - 24 теста, требующие БД, не запускались.
   - Можно поднять Postgres из compose, опубликовать порт или запускать тесты внутри контейнера.

3. **Голос**
   - `STT_API_KEY` пустой, провайдер, вероятно, отключён.
   - Голосовой сценарий не проверялся.

4. **Персистентность**
   - История диалога и pending-actions пока in-memory: после рестарта теряются.
   - Таблицы `sessions`, `messages`, `pending_actions` уже есть — нужно перенести туда.

5. **`GET /sessions/{id}/messages`**
   - Описан в контракте, но не реализован.

6. **Таймзона пользователя**
   - Бот использует `APP_TZ`; `/settings` или определение из Telegram не сделаны.
   - `answer_clarification` уже принимает `timezone`, но бот всегда передаёт общую.

7. **Запрет «нажми кнопку»**
   - Сейчас только в системном промпте.
   - Если модель начнёт игнорировать, нужна детерминированная постобработка ответа.

8. **`onboarding_seen`**
   - Хранится в `MemoryStorage` и сбрасывается при рестарте бота.

9. **Веб-авторизация и разделение аккаунтов**
   - Не делались. План зафиксирован в `DEVLOG.md`.
   - Сейчас web использует `X-Demo-User`.

10. **Живой сценарий группы**
    - Код использует `from_user.id`, но в реальном групповом чате не проверялся.

## Как запустить завтра

```powershell
cd project
docker compose -f infra/docker/docker-compose.yml up -d --build
docker compose -f infra/docker/docker-compose.yml ps
docker compose -f infra/docker/docker-compose.yml logs -f bot
```

```powershell
cd project
backend\.venv\Scripts\python.exe scripts\e2e\smoke.py
```

Для smoke нужны переменные из `.env`, в частности `BOT_INTERNAL_SECRET`.
