# Scripts

Вспомогательные скрипты. Владелец — A, кроме деплой-скриптов (B).

| Скрипт | Владелец | Назначение |
|---|---|---|
| `import_csv.py` | A | импорт `voice_assistant_events_1000_*.csv` в БД |
| `seed_demo.py` | A | demo-user и базовые события для показа |
| `eval_search.py` | A | golden-set, Recall@5/MRR, проверка падежей и опечаток |
| `eval_nlu.py` | вместе | 50–100 фраз: intent, слоты, даты |
| `deploy.sh` | B | сборка и деплой (не хранить секреты) |

## Правила импорта CSV

- Читать UTF-8 с BOM.
- Классифицировать тип: `встреча/созвон/планёрка/демо` → `meeting`,
  `напомнить` → `reminder`, иначе `task`.
- Даты 2024–2027, время 08:00–20:00.
- 1000 строк, 376 уникальных текстов; 624 дубля — опционально дедуплицировать
  по `(title, date, time)`.
- Не считать датасет «пользовательскими данными»: это seed/корпус для проверки
  поиска, в README это указать.
