# Frontend

Веб-клиент к тому же API, что и Telegram-бот: регистрация/вход, чат,
таймлайн, поиск и запись голоса из браузера. React 18 + TypeScript + Vite,
без UI-библиотек.

Подробное описание продукта, auth-потока и дизайн-системы:
[`../docs/web.md`](../docs/web.md).

## Запуск

```bash
cd project/frontend
npm install
npm run dev
```

Vite открывает `http://localhost:5173` и проксирует `/api` на
`http://127.0.0.1:8000`. Backend должен быть запущен.

```bash
npm run build
npm run preview
```

`npm run build` выполняет `tsc -b` и production-сборку в `dist/`.

## Переменные

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `VITE_API_BASE_URL` | `/api/v1` | базовый URL API |

Пользователь входит по email и паролю. Access-токен хранится в
`localStorage` под ключом `gorky-auth-token` и передаётся в
`Authorization: Bearer ...`.

## Что реализовано

- Экран входа/регистрации с ASCII-роботом и анимацией.
- Чат: текст, ответы, уточнения с быстрыми вариантами, голосовой ввод через
  `MediaRecorder`.
- Таймлайн: сегодня / 7 дней / 30 дней / все, создание, выполнение и удаление
  событий.
- Поиск по названию и описанию с сниппетами и score.
- Чёрно-белая адаптивная вёрстка для телефона и десктопа.

## Ограничения

- TTS пока не подключён: `audio_url` не воспроизводится.
- Для микрофона нужен `localhost` или HTTPS.
- Мок-режим не используется: фронтенд работает с реальным API.
- История чата живёт в памяти страницы; `session_id` сохраняется в
  localStorage.
- Нет UI редактирования события и восстановления пароля.
